# Локальный Moonlight-пробник

Передаёт рабочий стол собственного ПК с Sunshine на Switch: H.264, stereo Opus,
геймпад, мышь и ввод текста. Использует вывод NVTEGRA/SDL из FogPlay NX и отдельный
Moonlight-транспорт. Не обращается к МТС/FogHub и не создаёт аренды.

Версия 0.1.1 исправляет клиентский TLS для сопряжения с Sunshine: отдельная сборка
curl с mbedTLS поддерживает существующие PEM-ключи клиента. Основная библиотека
curl и клиент МТС не изменяются. Журнал содержит этапы HTTP/HTTPS, коды curl/HTTP
и длительность запросов; тела ответов, PIN и ключи в него не записываются.

## Запуск

1. Подготовьте Sunshine на ПК и включите приложение **Desktop**. Для Windows
   требуется ViGEmBus, чтобы проверить виртуальный Xbox-геймпад. Видео/звук работают
   без него. ПК и Switch должны находиться в одной доверенной локальной сети.
2. Скопируйте архив SD в корень карты. Файлы будут в `switch/fogplay_nx`:
   `moonlight_probe.nro` и `moonlight-test.json`. Основной `fogplay_nx.nro`, вход,
   настройки и история приложения не заменяются.
3. В `moonlight-test.json` укажите LAN IPv4 ПК. Значения по умолчанию: H.264,
   1280×720, 60 FPS, 10000 кбит/с. `app_id=0` выбирает Desktop по имени.
4. Запустите **FogPlay Moonlight Local Test** в hbmenu через удержание **R** при
   запуске установленной игры. Album не поддерживается.
5. Нажмите **A**. При первом подключении введите показанный PIN на странице **PIN**
   веб-интерфейса Sunshine на ПК; в Device Name задайте, например, Nintendo Switch.
   После сопряжения подключение продолжится само. При сохранённом сопряжении новый
   PIN не потребуется. После ошибки перезапустите пробник и используйте новый PIN.
6. Проверьте движение изображения, звук, кнопки и стики. На ПК можно открыть
   локальную страницу теста геймпада или `joy.cpl`.

На этом этапе используйте свободный хост и не подключайте второй Moonlight-клиент
параллельно. Уже запущенное приложение пробник не перехватывает. Если ранее был
обрыв/неопределённый запуск, сначала вручную закройте ту сессию в Sunshine.

## Управление и выход

- Nintendo **B/A/Y/X** передаются как Xbox **A/B/X/Y**; стики, крестовина и курки
  передаются напрямую. Короткий Minus отправляет Back после отпускания.
- **Minus + Plus** — меню: мышь, текст с экранной клавиатуры, остановка, закрытие.
- В режиме мыши левый стик или экран двигают указатель; ZR — левый клик, ZL — правый.
- Пока идёт подключение, **B** отменяет его. После завершения **+** выходит в hbmenu.
- HOME/потеря фокуса останавливают поток и запускают проверку/закрытие приложения,
  которое открыл пробник. При сетевой ошибке подтверждения может не быть — статус
  сообщает о необходимости проверки Sunshine.

Сопряжение сохраняется в `switch/fogplay_nx/moonlight-test-identity`. Там закрытый
ключ клиента: не публикуйте эту папку. PIN, ключи и вводимый текст в журнал не пишутся.
Журнал: `switch/fogplay_nx/moonlight-test.log`, перезаписывается при следующем запуске.
Скопируйте его перед повторным тестом, если нужно сохранить неудачный запуск.

## Сборка

Окружение основного проекта плюс Switch portlibs `expat` и `mbedtls`.

```sh
bash tools/moonlight-probe/build.sh
bash tools/moonlight-probe/test.sh
python3 tools/moonlight-probe/package.py --host 192.168.1.10
```

Результат находится в `tools/moonlight-probe/dist`. `package.py` проверяет NRO,
путь SD и содержимое архива. Локальные файлы credentials/config не подхватываются.
Источники и изменения Moonlight закреплены в `tools/moonlight`; лицензии —
`licenses/moonlight`. Сторонний код пробника содержит GPL-3.0-компоненты; лицензия
собственного кода GPL-2.0-or-later допускает применение более поздней версии.
Этот диагностический комплект не является подготовленным публичным релизом:
для публикации бинарника нужен также полный комплект соответствующих исходников
включённых библиотек и изменений.

## Границы проверки

Host-тесты проверяют конфигурацию, владение локальным запуском, отмену, неопределённый
ответ, сборку кадров и очереди. Switch-сборка подтверждает компиляцию и линковку;
pairing, аппаратное видео, звук и реальный ввод проверяются на консоли.

Пробник ограничен доверенной LAN: HTTPS-сертификат GameStream-хоста пока не закреплён.
Производственный FH-транспорт будет отдельным адаптером общих интерфейсов; этот
пробник не включает карточки FH, аренду, PS-тачпад или гироскоп. Наличие корректного
потока Moonlight само по себе не доказывает создание/завершение аренды FogHub.
